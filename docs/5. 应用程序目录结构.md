```
│   └── sparkrobot-common/# 通用库
├── robot-cloud/          # 云端服务
│   ├── 前端/             # Vue3 前端应用
│   └── 后端/             # Node.js + Python 后端服务
└── robot-phone/          # 手机端应用
    └── RobotPhone/       # React Native 应用
```

## 通信协议

### WebSocket 通道

robot-agent 与 robot-cloud 后端之间通过多个 WebSocket 通道通信：

| 通道           | 用途                             | 方向            |
| -------------- | -------------------------------- | --------------- |
| business       | 业务消息（注册、文本、动作指令） | 双向            |
| control        | 控制消息（心跳、状态、摇杆）     | 双向            |
| audio_upload   | 音频上传（语音输入）             | 客户端 → 服务端 |
| audio_download | 音频下载（语音回复）             | 服务端 → 客户端 |

### HTTP API

- **robot-cloud 后端**: `http://localhost:3000/api/v1/*`
- **robot-server**: `http://机器狗IP:8080/api/v1/*`

## 快速开始

详细安装和运行说明请参考各子项目的文档。

### 开发环境要求

- **Python 3.10+**: robot-agent, robot-server, sparkrobot-common
- **Node.js 18+**: robot-cloud 前后端
- **React Native CLI**: robot-phone
- **系统依赖**: portaudio19-dev (音频采集)
