# 机器狗对话管理系统 - 技术文档

## 1. 系统概述

### 1.1 项目简介

机器狗对话管理系统是一个基于实时通信的智能对话平台，支持多台机器狗同时进行语音交互，并能通过AI大模型实现智能对话和动作控制。

### 1.2 核心功能

- 实时音频/文字输入处理
- 语音识别与合成
- AI大模型对话
- 机器狗动作控制
- 多设备并发管理
- 知识库检索增强

## 2. 技术架构

### 2.1 整体架构

```
┌─────────────────┐
│   机器狗客户端   │ (音频采集 + 动作执行)
└────────┬────────┘
         │ WebSocket + Opus
         ▼
┌─────────────────┐
│   WebSocket网关  │ (连接管理 + 消息路由)
└────────┬────────┘
         │
    ┌────┴────┬────────────┬──────────┐
    ▼         ▼            ▼          ▼
┌────────┐┌────────┐┌──────────┐┌─────────┐
│语音识别 ││语音合成 ││AI对话引擎││ 动作控制 │
└────────┘└────────┘└──────────┘└─────────┘
                         │
                    ┌────┴────┐
                    ▼         ▼
                ┌────────┐┌────────┐
                │ 知识库  ││日志系统│
                └────────┘└────────┘
```

### 2.2 技术栈

#### 后端技术

- **运行环境**: Node.js 24+ / TypeScript
- **Web框架**: Express.js
- **WebSocket**: ws / socket.io
- **音频处理**: opus / node-opus
- **语音识别**: 讯飞/阿里云/Azure ASR API
- **语音合成**: 讯飞/阿里云/Azure TTS API
- **AI模型**: OpenAI GPT-4 / Claude / 通义千问 / Deepseek
- **数据库**: SQLite / PostgreSQL
- **日志**: Winston
- **进程管理**: PM2

#### 前端技术（调试界面）

- Vue 3 + TypeScript
- WebSocket Client
- Audio API

#### 机器狗客户端

- Python 3.8+
- WebSocket Client (websockets库)
- PyAudio / sounddevice (音频采集)
- Opus编码器
- 机器狗SDK

                    "robotId": self.robot_id,

                        "channels": 1,

                    }
                }

**Q: 如何处理网络波动导致的音频丢包？**
A: 实现音频缓冲和重传机制，使用Opus的丢包隐藏功能。

**Q: 多台机器狗同时对话会互相干扰吗？**
A: 不会，每台机器狗有独立的会话管理，通过robotId隔离。

**Q: AI生成的动作指令如何保证安全？**
A: 通过白名单、参数限制、频率控制三重机制保障安全。

**Q: 知识库如何更新？**
