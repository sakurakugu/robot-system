## 📋 技术实现细节

### 安全机制
1. **动作白名单**：仅允许10个预定义的安全动作
2. **参数限制**：
   - walk_forward/backward: 最多3步
   - turn_left/right: 最多720度
3. **频率控制**：每个机器狗最多10次动作/分钟
4. **自动修正**：超出范围的参数自动调整到安全值

### 支持的动作列表
```
stand_up      - 站起来
sit_down      - 坐下
turn_left     - 左转 (最大720度)
turn_right    - 右转 (最大720度)
shake_hand    - 握手
wave          - 挥手
nod           - 点头
dance         - 跳舞
walk_forward  - 前进 (最多3步)
walk_backward - 后退 (最多3步)
```

### 消息协议

**动作指令格式**：
AI在回复中使用 `[ACTION:动作名(参数)]` 格式：
```
用户："坐下"
AI："好的主人[ACTION:sit_down()]"

用户："走两步"
AI："好的，我来走两步[ACTION:walk_forward(steps=2)]"
```

系统自动解析并发送WebSocket动作指令：
```json
{
  "type": "action_command",
  "robotId": "uuid",
  "data": {
    "action": "walk_forward",
    "parameters": {"steps": 2},
    "safetyChecked": true
  }
}
```

```bash

```

### 3. 测试
