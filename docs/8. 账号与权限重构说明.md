# 7. 账号与权限重构说明

## 本次完成内容

1. 新增统一账号体系（Web + 手机端共用）
- 支持注册、登录、退出、游客模式。
- 账号数据存储到 SQLite 数据库。
- 新增会话表，可追踪每个账号在哪些设备登录。

2. 新增权限模型
- `user`：普通用户。
- `admin`：管理员。
- `super_admin`：主管理员。
- 第一个注册成功的用户自动成为 `super_admin`。

3. 新增权限管理能力
- 主管理员可在 Web 端「用户权限管理」页面提升/降级其他账号角色。
- 保证至少存在一个主管理员，防止全部降级。

4. 管理功能按权限保护
- API Key / AI 机密配置修改：仅 `super_admin`。
- 更新管理（上传/回滚/删除）：`admin` 与 `super_admin`。
- 知识库增删改：`admin` 与 `super_admin`。
- 其他参数（UI 配置）修改：`admin` 与 `super_admin`。

5. 登录设备查看
- Web 端新增「登录设备」页，可查看当前账号所有活跃会话并下线其它设备。
- 手机端新增「登录设备」页，可查看并下线其它设备。

6. 机器人连接与用户体系隔离
- 机器人 WebSocket 连接继续独立工作。
- 机器人连接不会写入用户会话表，不计入登录设备。

## 数据库新增表

- `users`
  - `id`, `username`, `password_hash`, `role`, `created_at`, `updated_at`, `last_login_at`
- `user_sessions`
  - `id`, `user_id`, `token_hash`, `client_type`, `device_name`, `ip_address`, `user_agent`, `created_at`, `last_seen_at`, `expires_at`, `revoked_at`
- `knowledge_entries`
  - `id`, `title`, `content`, `tags`, `created_by`, `updated_by`, `created_at`, `updated_at`

## 新增后端接口（`/api/v1`）

### 账号认证
- `POST /auth/register`
- `POST /auth/login`
- `POST /auth/guest`
- `GET /auth/me`
- `POST /auth/logout`

### 登录设备
- `GET /auth/sessions`
- `DELETE /auth/sessions/:id`

### 用户权限管理
- `GET /auth/users`（admin/super_admin）
- `PUT /auth/users/:id/role`（super_admin）

### 知识库
- `GET /knowledge`
- `POST /knowledge`（admin/super_admin）
- `PUT /knowledge/:id`（admin/super_admin）
- `DELETE /knowledge/:id`（admin/super_admin）

## 前端（Web）改动

- 新增页面：
  - `/auth` 登录/注册/游客
  - `/sessions` 登录设备
  - `/users` 用户权限管理（仅主管理员）
- 主布局新增账号状态展示、登录/退出入口。
- 参数管理页接入 token 鉴权，且前端限制仅主管理员修改 API Key。
- 知识库页面改为真实 CRUD（对接后端）。

## 手机端改动

- 新增账号页面：`账号登录`（含注册、登录、游客模式）
- 新增页面：`登录设备`
- Profile 页展示当前账号（或游客）并提供登录/退出入口。
- `http` 请求封装已接入 Bearer token + 设备信息头。

## 鉴权请求头

客户端请求会自动携带：
- `Authorization: Bearer <token>`（登录后）
- `x-client-type: web | mobile`
- `x-device-name: <device info>`
