## 1. 技术栈

### 1.1 核心技术

- **框架**: Vue.js 3.5 (Composition API)

- **3D 渲染**: Three.js 0.182

### 1.3 开发工具

- **样式预处理**: Sass (sass-embedded)

## 4. 状态管理

### 4.1 Pinia Store

项目使用 Pinia 进行状态管理，当前实现的 Store：

#### 4.1.1 Theme Store (主题管理)

**文件**: `src/stores/theme.ts`

**状态**:

```typescript
{
  theme: 'light' | 'dark',           // 当前主题
  followSystem: boolean,              // 是否跟随系统
  mapping: {                          // 系统主题映射
    dark: Theme,
    light: Theme
  },
  _mql: MediaQueryList | null         // 媒体查询监听器
}
```

**方法**:

| 方法 | 参数 | 说明 |
|------|------|------|
| `init()` | 无 | 初始化主题，从 localStorage 恢复设置 |
| `setTheme(theme)` | theme: 'light' \| 'dark' | 切换主题 |
| `setFollowSystem(follow)` | follow: boolean | 设置是否跟随系统 |
| `setMapping(mapping)` | mapping: ThemeMapping | 设置系统主题映射 |
| `apply()` | 无 | 应用主题到 DOM |
| `setupSystemListener()` | 无 | 设置系统主题监听器 |

**本地存储键**:

- `app-theme`: 当前主题
- `app-theme-followSystem`: 是否跟随系统
- `app-theme-mapping`: 系统主题映射

#### 4.1.2 未来 Store 扩展

以下是建议添加的 Store：

- **Project Store**: 当前工程信息、机器人列表、时间轴数据
- **Execution Store**: 动作执行状态、日志输出
- **User Store**: 用户信息、偏好设置

## 7. WebSocket 通信

### 7.1 WebSocket 服务

**文件**: `src/services/websocket.ts`

```typescript
class WebSocketService {
  private ws: WebSocket | null = null
  private url: string = 'ws://localhost:3001'
  private reconnectInterval: number = 5000
  private handlers: Map<string, Function[]> = new Map()

  connect() {
    this.ws = new WebSocket(this.url)
    
    this.ws.onopen = () => {
      console.log('WebSocket 连接已建立')
      this.emit('connected')
    }
    
    this.ws.onmessage = (event) => {
      const data = JSON.parse(event.data)
      this.emit(data.type, data.payload)
    }
    
    this.ws.onclose = () => {
      console.log('WebSocket 连接已关闭')
      this.emit('disconnected')
      // 自动重连
      setTimeout(() => this.connect(), this.reconnectInterval)
    }
    
    this.ws.onerror = (error) => {
      console.error('WebSocket 错误:', error)
      this.emit('error', error)
    }
  }

  on(event: string, handler: Function) {
    if (!this.handlers.has(event)) {
      this.handlers.set(event, [])
    }
    this.handlers.get(event)!.push(handler)
  }

  off(event: string, handler: Function) {
    const handlers = this.handlers.get(event)
    if (handlers) {
      const index = handlers.indexOf(handler)
      if (index > -1) {
        handlers.splice(index, 1)
      }
    }
  }

  emit(event: string, data?: any) {
    const handlers = this.handlers.get(event)
    if (handlers) {
      handlers.forEach(handler => handler(data))
    }
  }

  send(type: string, payload: any) {
    if (this.ws && this.ws.readyState === WebSocket.OPEN) {
      this.ws.send(JSON.stringify({ type, payload }))
    }
  }

  disconnect() {
    if (this.ws) {
      this.ws.close()
      this.ws = null
    }
  }
}

export const wsService = new WebSocketService()
```

### 7.2 使用示例

```typescript
import { wsService } from '@/services/websocket'

// 连接 WebSocket
wsService.connect()

// 监听执行输出
wsService.on('execution.output', (data) => {
  console.log('执行输出:', data.output)
})

// 监听执行进度
wsService.on('execution.progress', (data) => {
  console.log('执行进度:', data.progress, data.message)
})

// 监听执行完成

  console.log('执行完成:', data.executionId)
})
```

## 9. 开发规范

### 9.1 组件命名规范

- **视图组件** (Views): PascalCase，如 `ProjectList.vue`
- **功能组件** (Components): PascalCase，如 `CodeEditor.vue`
- **组件文件夹**: kebab-case，如 `timeline/`

### 9.2 API 命名规范

- **API 文件**: kebab-case，如 `project.ts`
- **API 对象**: camelCase，如 `projectApi`
- **API 方法**: camelCase，动词开头，如 `getProjects()`, `createProject()`

### 9.3 状态管理规范

- **Store 文件**: kebab-case，如 `theme.ts`
- **Store 定义**: camelCase + Store 后缀，如 `useThemeStore`
- **State**: camelCase
- **Actions**: camelCase，动词开头

### 9.4 TypeScript 规范

- 所有组件使用 `<script setup lang="ts">`
- 所有 API 参数和返回值必须有类型定义
- 使用接口 (interface) 定义复杂类型
- 使用类型别名 (type) 定义联合类型

### 9.5 样式规范

- 组件样式使用 `<style scoped>` 或 `<style scoped lang="scss">`
- 全局样式放在 `src/styles/` 目录
- 使用 CSS 变量实现主题切换
- 避免使用内联样式

### 9.6 代码组织规范

**组件结构顺序**:

1. `<script setup>`: 导入 → 变量定义 → 函数定义 → 生命周期钩子
2. `<template>`: HTML 结构
3. `<style>`: 样式定义

**示例**:

```vue
<script setup lang="ts">
// 1. 导入
import { ref, onMounted } from 'vue'
import { projectApi } from '@/api/project'

// 2. 变量定义
const projects = ref([])
const loading = ref(false)

// 3. 函数定义
const loadProjects = async () => {
  loading.value = true
  try {
    const res = await projectApi.getProjects()
    projects.value = res.data
  } finally {
    loading.value = false
  }
}

// 4. 生命周期
onMounted(() => {
  loadProjects()
})
</script>

<template>
  <div class="project-list">
    <!-- 内容 -->
  </div>
</template>

<style scoped lang="scss">
.project-list {
  /* 样式 */
}
</style>
```
