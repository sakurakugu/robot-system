# 第 3 章 用 Python 写一个 AI 命令行助手

## 本章目标

这一章开始写代码。目标是做出一个最小命令行程序：

1. 运行脚本
2. 输入一句中文
3. 调用 AI
4. 打印出动作 JSON

## 本章完成效果

在终端运行：

```bash
python 01_ai_cli.py
```

然后输入：

```text
站起来，然后向前走两步
```

程序输出：

```json
{
  "actions": [
    {"action": "stand"},
    {"action": "forward", "steps": 2}
  ]
}
```

- 环境变量是什么


## 程序结构建议

建议把逻辑拆成三个小部分：

1. 读取用户输入
2. 调用 AI
3. 输出 JSON 结果

先不要一开始就加太多函数。

## 关键提醒

### 1. 先让输出稳定

这一章先别急着连机器狗，只要程序能稳定拿到 JSON 就算成功。

### 2. 先打印，不急着执行

很多初学者喜欢一边调用 AI，一边直接控制硬件。这样调试会很痛苦。

正确顺序是：

1. 先把 AI 输出打印出来
2. 确认格式对
3. 再考虑执行

## 推荐验证方法

建议至少测试下面几句：

- 站起来
- 向前走一步
- 向左转一下
- 站起来，然后向前走两步，再坐下

如果程序对这些句子都能稳定输出 JSON，就说明这一章已经成功。

## 对老师的建议

如果是给学生上课，建议把“调用 AI”封装得尽量短，让学生把注意力放在：

- 输入是什么
- 输出是什么
- JSON 长什么样

而不是一开始深究 HTTP 协议细节。
