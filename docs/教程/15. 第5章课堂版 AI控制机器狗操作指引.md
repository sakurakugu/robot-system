# 第 5 章课堂版 AI 控制机器狗操作指引

## 本章目标

这一章要把前面两条链路合并：

1. Python 调 AI
2. Python 控机器狗

## 本章完成效果

运行：

```bash
python 03_ai_control_dog.py
```

输入：

```text
让小狗站起来，然后向前走一步，再坐下
```

程序会：

1. 调用 AI
2. 打印动作 JSON
3. 打印准备执行的动作列表
4. 逐条执行动作

## 课堂建议

如果是第一次整合，建议先用：

```text
DOG_CONTROL_MODE=dry_run
DOG_CONFIRM_BEFORE_RUN=true
```

先让学生完整看懂流程，再切到真实机器狗。

## 课堂操作步骤

### 第一步：运行整合脚本

```bash
python 03_ai_control_dog.py
```

### 第二步：输入基础命令

建议从下面几句开始：

```text
站起来
向前走一步
站起来，然后向左转一下
站起来，然后向前走一步，再坐下
```

### 第三步：观察程序输出

让学生依次关注：

1. 自己输入了什么
2. AI 返回了什么
3. 程序准备执行什么
4. 最后执行了什么

## 老师现场讲解重点

### 重点 1：现在终于形成闭环了

这是第一次把“人话 -> AI -> Python -> 动作执行”连起来。

### 重点 2：动作白名单很重要

程序不是直接执行 AI 给的任意内容，而是先检查动作是否在允许范围内。

### 重点 3：执行前确认是安全保护

第一次接真实设备时，一定建议先确认再执行。

## 常见问题

### 问题 1：AI 输出对了，但程序没执行

先检查：

1. `actions` 是否为空
2. 动作名是否在支持范围内
3. 控制模式是否正确

### 问题 2：程序执行了，但动作幅度太大

处理：

- 调小 `DOG_FORWARD_SPEED`
- 调小 `DOG_STEP_SECONDS`
- 调小 `DOG_MAX_STEPS`
- 调小 `DOG_MAX_ANGLE`
