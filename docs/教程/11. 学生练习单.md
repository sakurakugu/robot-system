# 学生练习单

## 练习主题

用 AI 和 Python 做一个最小的机器狗控制项目。

## 第一部分：理解流程

请填空：

1. 用户输入一句中文后，第一步是由 ______ 来理解内容。
2. AI 输出的结果最好用 ______ 格式表示。
3. Python 程序拿到动作数据后，会去调用 ______ 控制机器狗。

## 第二部分：观察 JSON

请阅读下面这段数据：

```json
{
  "actions": [
    {"action": "stand"},
    {"action": "forward", "steps": 2},
    {"action": "sit"}
  ]
}
```

回答问题：

1. 一共有几个动作？
2. 第一个动作是什么？
3. 第二个动作走了几步？
4. 最后一个动作是什么？

## 第三部分：扣子练习

请在扣子里测试下面几句，并把输出结果记下来：

1. 站起来
2. 向前走两步
3. 向左转一下
4. 站起来，然后向前走一步，再坐下

请观察：

- 有没有多余文字
- 动作名是否正确
- 顺序是否正确

## 第四部分：Python CLI 练习

运行：

```bash
python 01_ai_cli.py
```

完成下面任务：

1. 输入 `站起来`
2. 输入 `向前走一步`
3. 输入 `站起来，然后向右转，再坐下`
4. 输入 `exit` 退出程序

## 第五部分：动作执行练习

运行：

```bash
python 02_dog_demo.py
```

观察程序输出了哪些动作。

请写下来：

1. 第一个动作
2. 第二个动作
3. 第三个动作
4. 第四个动作

## 第六部分：综合练习

运行：

```bash
python 03_ai_control_dog.py
```

输入一句你自己设计的命令，例如：

```text
站起来，然后向前走一步，再向左转一下
```

记录下面内容：

1. 你的输入是什么
2. AI 输出了什么
3. 程序执行了什么动作

## 第七部分：思考题

1. 为什么 AI 输出不能每次都不一样？
2. 为什么要先分别测试 AI 和机器狗，而不是一开始就合在一起？
3. 如果机器狗没有执行动作，你会先检查哪一层？

## 第八部分：我的小改动

请尝试做一个自己的小改动，并写下来：

1. 你改了什么
2. 为什么想这样改
3. 改完后的效果是什么
