# 第 1 章 我们要做什么

## 本章目标

这一章先不写代码，主要弄清楚三件事：

1. 我们最后到底要做出什么
2. 整个项目会经过哪几个步骤
3. 为什么这个项目要拆开学，而不是一口气做完

## 最终效果

我们希望最后能做到这样的效果：

1. 在命令行输入一句中文
2. AI 理解这句话的意思
3. Python 程序把 AI 的结果变成动作命令
4. 机器狗执行动作

例如输入：

```text
让小狗站起来，然后向前走两步
```

程序内部会发生下面的事情：

```text
学生输入
  ↓
AI 把中文变成动作 JSON
  ↓
Python 解析 JSON
  ↓
调用机器狗控制代码
  ↓
机器狗执行动作
```

## 为什么要做这个项目

这个项目相比与单纯聊天，和单纯控制硬件，把这两件事接起来是最小的的让“AI 控制真实世界设备”的方案：

- AI 负责“理解人说的话”
- Python 负责“把理解结果变成程序动作”
- 机器狗负责“真正执行动作”

之后还可以迁移到让AI使用别的工具上去。

## 整个教程路线

### 第一步：体验 AI

先不写代码，只在扣子里输入一句话，看看 AI 能不能把它转换成固定格式的动作数据。

### 第二步：写 Python 命令行程序

把上一步的体验搬到 Python 中，让学生自己写一个最小 CLI。

### 第三步：直接控制机器狗

先不接 AI，只让 Python 直接执行固定动作，确认机器狗能被控制。

### 第四步：组合成完整项目

把“AI 理解”和“机器狗执行”连起来，形成完整闭环。

## 这一套教程的规则

为了让学生更容易成功，我们会主动做简化。

### 规则 1：动作数量要少

第一版只学几个动作：

- 站起来
- 坐下
- 向前走
- 向后走
- 向左转
- 向右转

### 规则 2：AI 只能输出固定格式

AI 不能长篇解释，只能返回 JSON。

例如：

```json
{
  "actions": [
    {"action": "stand"},
    {"action": "forward", "steps": 2}
  ]
}
```

### 规则 3：先做单轮指令

第一版不做连续对话，只做：

- 输入一句话
- 执行一次
- 看结果

## 本章应该学到：

学完这一章，学生应该能说清楚：

1. 这个项目的目标是“用自然语言控制机器狗”
2. 这个项目分成 AI、Python、机器狗三部分
3. 我们要按照“先分开跑通，再合起来”的顺序学习

## 本章练习

试着用自己的话回答下面两个问题：

1. AI 在这个项目里负责什么
2. Python 在这个项目里负责什么

如果学生能说出：

- AI 负责把中文变成动作指令
- Python 负责调用 AI、解析结果、控制机器狗

就说明本章理解到位了。
