# 第 3 章课堂版 Python 调用 AI 操作指引

## 本章目标

这一章的目标很明确：

把“在扣子里看 AI 输出”变成“用 Python 程序自己调用 AI”。

## 本章完成效果

运行：

```bash
python 01_ai_cli.py
```

输入：

```text
站起来，然后向前走两步
```

程序输出：

```json
{
  "actions": [
    {"action": "stand"},
    {"action": "forward", "steps": 2}
  ]
}
```

## 上课前老师要准备什么

1. 确保学生电脑已经安装 Python
2. 确保学生已经拿到 API Key
3. 确保示例代码目录已经发给学生
4. 老师先自己完整跑通一遍

## 课堂操作步骤

### 第一步：进入示例代码目录

进入：

```text
docs/示例代码/机器狗AI入门
```

### 第二步：安装依赖

运行：

```bash
pip install -r requirements.txt
```

### 第三步：配置 `.env`

让学生复制 `.env.example` 为 `.env`，然后填写：

```text
OPENAI_API_KEY=自己的密钥
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_MODEL=gpt-4o-mini
DOG_CONTROL_MODE=dry_run
```

第一次上课时，`DOG_CONTROL_MODE` 一定建议保持为 `dry_run`。

### 第四步：运行命令行示例

运行：

```bash
python 01_ai_cli.py
```

### 第五步：输入测试命令

建议依次输入：

```text
站起来
向前走一步
向右转一下
站起来，然后向前走两步，再坐下
```

## 老师现场讲解重点

### 重点 1：从“网页调用”变成“代码调用”

前一章是在网页里试，这一章是 Python 帮我们自动做同样的事情。

### 重点 2：程序的输入输出要看清楚

输入是中文，输出是 JSON。

这就是本章最核心的转换。

### 重点 3：现在还不执行机器狗

这一章只看到动作结果，不控制机器狗。

这样调试会简单很多。

## 常见报错和处理

### 报错 1：找不到模块

现象：

```text
ModuleNotFoundError
```

处理：

- 确认已经执行 `pip install -r requirements.txt`

### 报错 2：没有 API Key

现象：

```text
未找到 OPENAI_API_KEY
```

处理：

- 确认 `.env` 已创建
- 确认变量名拼写正确

### 报错 3：返回的不是 JSON

处理：

- 检查 `prompts.py` 中的提示词
- 再强调“只能输出 JSON”

## 本章验收标准

学生只要完成下面三点就算通过：

1. 能运行 `01_ai_cli.py`
2. 能输入中文命令
3. 能稳定得到动作 JSON
