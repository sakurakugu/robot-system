# 课堂口令清单

## 基础口令

这些口令适合在第一轮测试时使用。

```text
站起来
坐下
向前走一步
向前走两步
向后退一步
向左转一下
向右转一下
```

## 组合口令

这些口令适合在第二轮测试时使用。

```text
站起来，然后向前走一步
站起来，然后向左转一下
站起来，然后向右转一下，再坐下
向前走一步，然后向后退一步
```

## 稍复杂口令

这些口令适合在 AI 输出已经比较稳定后使用。

```text
让小狗先站起来，再向前走两步，最后坐下
请让机器狗向右转一下，然后向前走一步
先站起来，再向左转一下，再向右转一下
```

## 不建议第一轮就测试的口令

下面这些句子不适合刚开始就测试，因为它们更容易让 AI 自由发挥：

```text
表演一下
开心一点
转一圈再做个可爱的动作
你自己决定做什么
```

## 课堂使用建议

建议老师按下面顺序发口令：

1. 先发基础口令
2. 再发组合口令
3. 最后再发稍复杂口令

这样学生更容易看到“从简单到复杂”的稳定变化。
