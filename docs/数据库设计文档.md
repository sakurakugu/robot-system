## 1. 数据库架构

### 1.1 技术选型

- **数据库类型**: SQLite 3
- **Node.js 库**: sqlite3 5.1.7
- **存储位置**: 本地文件系统
- **外键支持**: 已启用 (`PRAGMA foreign_keys = ON`)

### 1.2 架构设计理念

采用**主数据库 + 工程数据库**分离的架构：

```
数据目录/
├── main.db                 # 主数据库（全局信息）
└── 工程目录/
    ├── 工程1/
    │   ├── project.db      # 工程数据库（工程独立数据）
    │   ├── project.json    # 工程元数据
    │   ├── audio/          # 音频资源
    │   ├── custom_actions/ # 自定义动作脚本
    │   └── build/          # 构建输出
    └── 工程2/
        └── ...
```

**设计优势**:

1. **工程隔离**: 每个工程的数据独立存储，互不影响
2. **便于迁移**: 可以直接复制工程文件夹进行备份和分享
3. **性能优化**: 避免单一数据库过大导致的性能问题
4. **灵活扩展**: 新增工程时无需修改主数据库结构

## 2. 主数据库 (main.db)

### 2.1 用户表 (users)

存储用户信息（当前为单用户模式，预留多用户支持）。

```sql
CREATE TABLE IF NOT EXISTS users (
  uuid TEXT PRIMARY KEY,                                             -- 用户唯一标识(UUIDv7)
  username TEXT NOT NULL,                                            -- 用户名
  password_hash TEXT,                                                -- 密码哈希值（预留）
  created_at TEXT DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now')),   -- 创建时间(UTC, ISO 8601)
  updated_at TEXT DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now'))    -- 更新时间(UTC, ISO 8601)
);
```

**字段说明**:

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| uuid | TEXT | PRIMARY KEY | 用户唯一标识（UUIDv7 格式） |
| username | TEXT | NOT NULL | 用户名 |
| password_hash | TEXT | NULL | 密码哈希（预留，当前未使用） |
| created_at | TEXT | DEFAULT | 创建时间（UTC，ISO 8601 格式） |
| updated_at | TEXT | DEFAULT | 更新时间（UTC，ISO 8601 格式） |

**默认用户**:

```sql
INSERT INTO users (uuid, username) VALUES 
('00000000-0000-0000-0000-000000000000', 'default');
```

**说明**: 单用户模式下，所有工程的 `user_uuid` 都指向这个默认用户。

### 2.2 工程索引表 (project_index)

存储所有工程的元信息和路径索引。

```sql
CREATE TABLE IF NOT EXISTS project_index (
  uuid TEXT PRIMARY KEY,                                              -- 工程唯一标识(UUIDv7)
  user_uuid TEXT NOT NULL,                                            -- 所属用户UUID
  name TEXT NOT NULL,                                                 -- 工程名称
  description TEXT,                                                   -- 工程描述
  folder_path TEXT NOT NULL,                                          -- 工程文件夹绝对路径
  thumbnail_path TEXT,                                                -- 工程缩略图路径
  last_opened TEXT,                                                   -- 最后打开时间(UTC, ISO 8601)
  created_at TEXT DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now')),    -- 创建时间(UTC, ISO 8601)
  updated_at TEXT DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now')),    -- 更新时间(UTC, ISO 8601)
  FOREIGN KEY (user_uuid) REFERENCES users(uuid)                      -- 外键：关联 users 表
);

CREATE INDEX IF NOT EXISTS idx_user_uuid ON project_index(user_uuid);
CREATE INDEX IF NOT EXISTS idx_last_opened ON project_index(last_opened DESC);
```

**字段说明**:

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| uuid | TEXT | PRIMARY KEY | 工程唯一标识（UUIDv7） |
| user_uuid | TEXT | NOT NULL, FK | 所属用户UUID |
| name | TEXT | NOT NULL | 工程名称 |
| description | TEXT | NULL | 工程描述 |
| folder_path | TEXT | NOT NULL | 工程文件夹的绝对路径 |
| thumbnail_path | TEXT | NULL | 工程缩略图路径（相对或绝对） |
| last_opened | TEXT | NULL | 最后打开时间 |
| created_at | TEXT | DEFAULT | 创建时间 |
| updated_at | TEXT | DEFAULT | 更新时间 |

**索引说明**:

- `idx_user_uuid`: 加速按用户查询工程
- `idx_last_opened`: 加速按最近打开时间排序

**示例数据**:

```sql
INSERT INTO project_index (uuid, user_uuid, name, description, folder_path) VALUES 
(
  '01939e7a-1234-7890-abcd-ef1234567890',
  '00000000-0000-0000-0000-000000000000',
  '我的机器狗项目',
  '双狗协同舞蹈表演',
  '/home/user/Documents/RobotDogControlProjects/我的项目_01939e7a'
);
```

## 3. 工程数据库 (project.db)

每个工程目录下都有一个独立的 `project.db` 文件，存储该工程的所有详细数据。

### 3.1 工程配置表 (project_config)

存储工程的配置信息（键值对形式）。

```sql
CREATE TABLE IF NOT EXISTS project_config (
  key TEXT PRIMARY KEY,                                             -- 配置项键
  value TEXT NOT NULL,                                              -- 配置项值（JSON 字符串）
  updated_at TEXT DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now'))   -- 更新时间
);
```

**字段说明**:

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| key | TEXT | PRIMARY KEY | 配置项键名 |
| value | TEXT | NOT NULL | 配置项值（通常为 JSON 字符串） |
| updated_at | TEXT | DEFAULT | 更新时间 |

**初始化配置**:

```sql
INSERT INTO project_config (key, value) VALUES 
('project_uuid', '"01939e7a-1234-7890-abcd-ef1234567890"'),
('project_version', '"1.0.0"'),
```

**常用配置项**:

| Key | Value 示例 | 说明 |
|-----|-----------|------|
| project_uuid | "01939e7a-..." | 工程 UUID |
| project_version | "1.0.0" | 工程数据库版本 |

### 3.2 机器人表 (robots)

存储工程中的机器人信息。

```sql
CREATE TABLE IF NOT EXISTS robots (
  uuid TEXT PRIMARY KEY,                                              -- 机器人唯一标识(UUIDv7)

  robot_ip TEXT NOT NULL,                                             -- 机器人IP地址

  local_port INTEGER NOT NULL,                                        -- 本地端口
  group_name TEXT,                                                    -- 机器人分组名称
  status TEXT DEFAULT 'offline',                                      -- 机器人状态
  created_at TEXT DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now')),    -- 创建时间
  updated_at TEXT DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now'))     -- 更新时间
);

CREATE INDEX IF NOT EXISTS idx_robot_name ON robots(name);
CREATE INDEX IF NOT EXISTS idx_robot_group ON robots(group_name);
```

**字段说明**:

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| uuid | TEXT | PRIMARY KEY | 机器人唯一标识（UUIDv7） |
| name | TEXT | NOT NULL | 机器人名称（如 "131"） |
| robot_ip | TEXT | NOT NULL | 机器人 IP 地址 |

| status | TEXT | DEFAULT 'offline' | 机器人状态（online/offline/error） |

| updated_at | TEXT | DEFAULT | 更新时间 |

**索引说明**:

- `idx_robot_name`: 加速按名称查询
- `idx_robot_group`: 加速按分组查询

```typescript
export class Database {

  // 查询多条记录

```

### 4.2 主数据库操作

```typescript
import { getMainDatabase } from './database';

// 获取主数据库实例（单例）
const db = await getMainDatabase();

// 查询所有工程
const projects = await db.all('SELECT * FROM project_index WHERE user_uuid = ?', [userUuid]);

// 插入新工程
await db.run(
  'INSERT INTO project_index (uuid, user_uuid, name, folder_path) VALUES (?, ?, ?, ?)',
  [uuid, userUuid, name, folderPath]
);

// 更新工程信息
await db.run(
  'UPDATE project_index SET name = ?, description = ?, updated_at = ? WHERE uuid = ?',
  [name, description, new Date().toISOString(), uuid]
);

// 删除工程
await db.run('DELETE FROM project_index WHERE uuid = ?', [uuid]);
```

### 4.3 工程数据库操作

```typescript
import { ProjectDatabase } from './database';

// 创建工程数据库实例
const projectDb = new ProjectDatabase('/path/to/project.db');
await projectDb.open();

// 初始化表结构
await projectDb.initTables();

// 查询机器人列表

// 添加机器人
await projectDb.run(
  'INSERT INTO robots (uuid, name, robot_ip, local_ip, local_port) VALUES (?, ?, ?, ?, ?)',
  [uuid, name, robotIp, localIp, localPort]
);

// 更新机器人状态
await projectDb.run(
  'UPDATE robots SET status = ?, updated_at = ? WHERE uuid = ?',
  ['online', new Date().toISOString(), uuid]
);

// 删除机器人
await projectDb.run('DELETE FROM robots WHERE uuid = ?', [uuid]);

// 关闭数据库
await projectDb.close();
```

### 4.4 事务支持

SQLite 支持事务，可通过 `BEGIN`、`COMMIT`、`ROLLBACK` 控制：

```typescript
try {
  await db.run('BEGIN TRANSACTION');
  
  // 执行多个操作
  await db.run('INSERT INTO ...');
  await db.run('UPDATE ...');
  
  await db.run('COMMIT');
} catch (error) {
  await db.run('ROLLBACK');
  throw error;
}
```

## 5. UUID 生成

### 5.1 UUID 版本选择

项目使用 **UUIDv7**，相比传统的 UUIDv4 有以下优势：

- **时间排序**: 包含时间戳信息，按生成时间自然排序
- **索引友好**: 对 B-Tree 索引更友好，提升查询性能
- **全局唯一**: 仍然保持全局唯一性

### 5.2 生成方法

**后端 (TypeScript)**:

```typescript
import { v7 as uuidv7 } from 'uuid';

const uuid = uuidv7();
// 示例: "01939e7a-1234-7890-abcd-ef1234567890"
```

### 5.3 UUID 使用场景

| 实体 | 字段名 | 说明 |
|------|--------|------|
| 用户 | uuid | 用户唯一标识 |
| 工程 | uuid | 工程唯一标识 |
| 机器人 | uuid | 机器人唯一标识 |
| 时间轴 | uuid | 时间轴唯一标识 |
| 图层 | uuid | 图层唯一标识 |
| 动作块 | uuid | 动作块唯一标识 |

## 6. 数据迁移策略

### 6.1 版本管理

#### 6.1.1 主数据库版本

可在主数据库中添加版本信息：

```sql
CREATE TABLE IF NOT EXISTS db_version (
  version TEXT PRIMARY KEY,
  applied_at TEXT DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now'))
);

INSERT INTO db_version (version) VALUES ('1.0.0');
```

#### 6.1.2 工程数据库版本

在 `project_config` 表中记录：

```sql
INSERT INTO project_config (key, value) VALUES 
('db_version', '"1.0.0"');
```

### 6.2 迁移流程

#### 6.2.1 主数据库迁移

1. 应用启动时检查 `db_version` 表
2. 对比当前应用支持的版本
3. 如果版本不匹配，执行迁移脚本
4. 更新版本号

**示例迁移脚本**:

```typescript
// migrations/001_add_thumbnail.ts
export async function up(db: Database) {
  await db.run(`
    ALTER TABLE project_index 
    ADD COLUMN thumbnail_path TEXT
  `);
  console.log('迁移 001: 添加缩略图字段完成');
}

export async function down(db: Database) {
  // SQLite 不支持直接删除列，需要重建表
  console.log('迁移 001: 回滚不支持');
}
```

#### 6.2.2 工程数据库迁移

1. 打开工程时检查 `project_config` 中的 `db_version`
2. 如果版本不匹配，执行迁移
3. 迁移前自动备份 `project.db`
4. 更新版本号

**备份策略**:

```typescript
import fs from 'fs';
import path from 'path';

// 备份工程数据库
function backupProjectDb(projectPath: string) {
  const dbPath = path.join(projectPath, 'project.db');
  const backupPath = path.join(
    projectPath,
    'backups',
    `project_${new Date().toISOString().replace(/:/g, '-')}.db`
  );
  fs.copyFileSync(dbPath, backupPath);
  console.log(`数据库已备份至: ${backupPath}`);
}
```

### 6.3 迁移管理器

```typescript
interface Migration {
  version: string;
  up: (db: Database) => Promise<void>;
  down: (db: Database) => Promise<void>;
}

class MigrationManager {
  private migrations: Migration[] = [];
  
  register(migration: Migration) {
    this.migrations.push(migration);
    // 按版本号排序
    this.migrations.sort((a, b) => a.version.localeCompare(b.version));
  }
  
  async migrate(db: Database, targetVersion: string) {
    const currentVersion = await this.getCurrentVersion(db);
    
    for (const migration of this.migrations) {
      if (migration.version > currentVersion && migration.version <= targetVersion) {
        console.log(`执行迁移: ${migration.version}`);
        await migration.up(db);
        await this.updateVersion(db, migration.version);
      }
    }
  }
  
  private async getCurrentVersion(db: Database): Promise<string> {
    const result = await db.get<{ version: string }>(
      'SELECT version FROM db_version ORDER BY version DESC LIMIT 1'
    );
    return result?.version || '0.0.0';
  }
  
  private async updateVersion(db: Database, version: string) {
    await db.run(
      'INSERT INTO db_version (version) VALUES (?)',
      [version]
    );
  }
}
```

## 附录

### A. SQLite 数据类型

| 类型 | 说明 | 示例 |
|------|------|------|
| TEXT | 文本字符串 | 'Hello', '2026-01-13T10:00:00Z' |
| INTEGER | 整数 | 42, 10131 |
| REAL | 浮点数 | 3.14, 0.5 |
| BLOB | 二进制数据 | （一般不使用） |
| NULL | 空值 | NULL |

**注意**: SQLite 没有专门的日期时间类型，项目中使用 TEXT 类型存储 ISO 8601 格式的时间字符串。

### B. 时间格式说明

项目统一使用 **ISO 8601** 格式的 UTC 时间：

```
2026-01-13T10:30:45.123Z
```

**生成方法**:

```typescript
// JavaScript/TypeScript
const now = new Date().toISOString();

// SQLite
strftime('%Y-%m-%dT%H:%M:%fZ', 'now')
```

### C. 索引优化建议

**何时创建索引**:

1. 外键列（如 `user_uuid`, `robot_uuid`）
2. 经常用于排序的列（如 `last_opened`, `created_at`）
3. 经常用于筛选的列（如 `name`, `group_name`）

**何时不创建索引**:

1. 表数据量很小（< 1000 行）
2. 列的基数很低（如 `status` 只有 2-3 种值）
3. 列很少用于查询条件

### D. 查询优化示例

**使用参数化查询（防止 SQL 注入）**:

```typescript
// ✅ 正确
await db.all('SELECT * FROM robots WHERE name = ?', [name]);

// ❌ 错误
await db.all(`SELECT * FROM robots WHERE name = '${name}'`);
```

**使用索引加速查询**:

```typescript
// 已有索引 idx_last_opened
const projects = await db.all(`
  SELECT * FROM project_index 
  WHERE user_uuid = ? 
  ORDER BY last_opened DESC 
  LIMIT 10
`, [userUuid]);
```

### E. 数据库维护

**定期优化数据库**:

```typescript
// 清理未使用的空间
await db.run('VACUUM');

// 分析查询优化
await db.run('ANALYZE');
```

**检查数据库完整性**:

```typescript
const result = await db.get('PRAGMA integrity_check');
console.log('数据库完整性:', result);
```
