# 应用程序目录结构

本文档详细介绍当前工作区中各业务仓的架构和功能。

## 目录概览

```text
repos/
├── robot-onboard/         # 机器狗本体端
│   ├── robot-agent/       # 对外通信代理
│   ├── robot-server/      # 本地 HTTP 配置与遥测服务
│   ├── robot-runtime/     # 本体运行时内核
│   ├── robot-ros/         # ROS2 雷达 / 建图 / 导航工作空间
│   └── sparkrobot-common/ # 通用库
├── robot-cloud/           # 云端服务
│   ├── 前端/              # Vue 3 前端应用
│   └── 后端/              # Node.js 后端服务
├── robot-pc/              # 电脑端工作站
│   ├── 前端/              # Vue 3 工作站前端
│   ├── 后端/              # Node.js 本地 API / WebSocket
│   └── docs/              # 工作站设计文档
└── robot-phone/           # 手机端应用
    ├── android/           # Android 工程
    ├── ios/               # iOS 工程
    └── src/               # React Native 业务代码
```

## 通信协议

### 云端 WebSocket 通道

`robot-agent` 与 `robot-cloud` 后端之间通过多个 WebSocket 通道通信：

| 通道           | 用途                             | 方向            |
| -------------- | -------------------------------- | --------------- |
| business       | 业务消息（注册、文本、动作指令） | 双向            |
| control        | 控制消息（心跳、状态、摇杆）     | 双向            |
| audio_upload   | 音频上传（语音输入）             | 客户端 → 服务端 |
| audio_download | 音频下载（语音回复）             | 服务端 → 客户端 |

### 工作站局域网链路

- **工作站前端 → 工作站后端**：`http://<工作站IP>:9010/api/v1/*`
- **robot-agent → 工作站后端**：`ws://<工作站IP>:9010/api/v1/web/business?robotId=<robotId>&role=robot`
- **工作站后端 → robot-server**：`http://<robotIp>:8080/api/v1/*`

### HTTP API

- **robot-cloud 后端**：`http://<cloudHost>/api/v1/*`
- **robot-pc 后端**：`http://<pcHost>:9010/api/v1/*`
- **robot-server**：`http://<robotIp>:8080/api/v1/*`

## 快速开始

详细安装和运行说明请参考各子项目的文档。

### 开发环境要求

- **Python 3.10+**：`robot-onboard` 相关模块
- **Node.js 24+**：`robot-cloud`、`robot-pc`
- **Node.js 20+ / React Native 环境**：`robot-phone`
- **React Native CLI**：`robot-phone`
- **ROS2 Humble**：`robot-onboard/robot-ros`
- **系统依赖**：`portaudio19-dev` 等音频采集依赖
